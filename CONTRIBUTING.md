# Contributing to FlowSpark Kids

Thanks for helping make science easier to see.

## Before opening a change

1. Keep child-facing language short and warm.
2. Prefer educational clarity over perfect physical accuracy.
3. Check keyboard focus and the mobile layout.
4. Avoid copyrighted images, sounds, and characters.

## Local checks

```bash
npm run lint
npm run test
npm run build
```

Small, focused commits are easiest to review.
